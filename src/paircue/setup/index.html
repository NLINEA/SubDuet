CONNECT YOUR LIBRARY

Where can SubDuet reach your media?

SubDuet needs read and write access. On a desktop, choose the mounted folder.
Where do I find these details?

In Plex, use the server address ending in :32400. Find the token by opening an item in Plex Web, choosing Get Info → View XML, and copying the X-Plex-Token value from the URL.

In Jellyfin Dashboard, open Advanced → API Keys to create a key. Open your user in Dashboard and copy its ID from the browser address.

In Emby Server Dashboard, open Advanced → API Keys to create a key. Open the selected user to find its user ID.
