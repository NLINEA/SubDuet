# SubDuet demo subtitles

These short synthetic subtitles were written for SubDuet and are covered by the repository's MIT
license. They contain no dialogue from a film, show, or other subtitle source.

Generate the bilingual result without a server, account, API key, or network request:

```bash
subduet pair examples/demo.en.srt examples/demo.es.srt -o examples/demo.mul.srt
```

The Spanish learning line appears first and the English source line second. SubDuet matches by
timing rather than subtitle number.
