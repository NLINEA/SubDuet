# SubDuet community standards

SubDuet welcomes people who want to make private media libraries more useful for language learning.
Participation should remain safe, practical, and respectful.

## Expected

- Be kind and specific when discussing a problem or disagreeing with an idea.
- Make room for different technical backgrounds, languages, accessibility needs, and media setups.
- Critique behavior, code, and product choices rather than people.
- Respect privacy, copyright, licenses, and the provenance of code or sample content.
- Accept a maintainer decision without harassment, even when continuing the technical discussion.

## Not accepted

- Harassment, threats, discrimination, sexualized attention, or targeted humiliation.
- Publishing another person's identity, credentials, private paths, logs, or library information.
- Sharing pirated media, unauthorized subtitles, copied product code, or instructions intended to
  bypass service access controls.
- Spam, coordinated disruption, or repeated bad-faith demands.

## Moderation

Maintainers may edit or remove content, close discussions, reject contributions, or restrict
participation when these standards are broken. Decisions should protect the community and project,
and should be explained when doing so would not expose private information or create further harm.

For ordinary concerns, contact the maintainers through a GitHub Discussion. For sensitive abuse,
use GitHub's private reporting or platform report tools rather than posting details publicly.

These standards apply in SubDuet repositories, discussions, issues, pull requests, and project-led
community spaces.
