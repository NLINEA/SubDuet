# SubDuet roadmap

SubDuet's product promise is narrow: turn a private media library into a portable bilingual
learning library, without replacing the player's existing experience.

This is a direction, not a release-date promise. Priorities may change after real beta feedback.

## Now — make the first result dependable

- Help the first ten independent beta users reach one bilingual subtitle without live help.
- Preserve every user-owned subtitle by default and make all network use explicit.
- Improve unsigned-app guidance, release verification, and first-run diagnostics.
- Learn which language pairs, players, and failure points matter most.

## Next — make language learning feel native

- Friendlier language and regional-style selection without requiring language-tag knowledge.
- Clearer output naming and player-specific “make it appear” guidance.
- More visible timing-confidence explanations and safe recovery choices.
- Easier installation through trusted package managers after the desktop flow stabilizes.

## Later — widen access without widening the product

- A documented interface for additional self-hosted translation or transcription providers.
- Optional local/offline language backends when quality and licensing are verifiable.
- Better very-large-library scanning and resumable work.
- Community-maintained platform and language recipes.

## Deliberately not the headline

SubDuet is not trying to become a media player, hosted subtitle account, analytics product, torrent
client, or replacement for library managers. Download Station remains optional and isolated. New
features should strengthen the bilingual-learning result, privacy, or ease of use.
